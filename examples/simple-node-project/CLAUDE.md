# CLAUDE.md

## Project Overview

Simple Node.js/TypeScript project.

## Project Structure

```
.
├── src/           # Source code
├── tests/         # Test files
├── package.json
└── tsconfig.json
```

## Development Commands

```bash
npm install        # Install dependencies
npm run dev        # Run development
npm run build      # Build for production
npm test           # Run tests
npm run lint       # Lint code
```

## Tech Stack

- Node.js 20+
- TypeScript 5
- Vitest (testing)
- ESLint + Prettier

## Conventions

### Git Commits
- Format: `[type] description`
- Types: `[feature]`, `[fix]`, `[docs]`, `[refactor]`, `[test]`
